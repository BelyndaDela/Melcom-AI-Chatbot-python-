# Melcom AI Chatbot

A beginner-friendly Flask-based customer service and shopping assistant for a Melcom-themed e-commerce project.

## Features

- Product assistance
- Demo product recommendations
- Order and delivery questions
- Returns, refunds and exchanges
- Branch/store questions
- Payment questions
- Web chat interface

## Run locally

```bash
python -m pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.

> Demo prices are sample data only and are not verified current Melcom prices.
